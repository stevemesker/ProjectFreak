
Files will all be named as the following:
`Type_ Category Name_ Subcategory Name_ Object Name_ number count`
number count *ALWAYS* starts with *0*. If an object is truly unique it does not have to have the count but I recommend using it anyway to be safe

Example:
3d model of an enemy - `M_Boss_Void_VoidHunter_0.fbx`

---
File type list

| Type | Description                             |
| :--- | :-------------------------------------- |
| M    | Mesh - 3d models                        |
| T    | Texture - any 2d bitmap image           |
| MAT  | Material - materials applied to a model |
| SHA  | Shader - custom shaders                 |
| PFB  | Prefab - prefab assemblies              |
| SCN  | Scene - unity scenes                    |
| SO   | Scriptable Object - Scriptable Objects  |
