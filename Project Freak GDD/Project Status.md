## Chapters
The chapters the work is split into, in order. Each card's `chapter` uses these names, spelled exactly. Add new chapters here; the tables below and the By Chapter and Chapter Table tabs on each board pick them up on their own.

| Chapter | Trello color |
| :-- | :-- |
| Chapter 0 Game Flow | Purple |
| Chapter 1 Combat | Green |
| Chapter 2 Inventory | Purple |
| Chapter 3 Crafting | Blue (rune field) |
| Chapter 4 Shades | Pink |
| Chapter 5 Art | Orange |

Names start with "Chapter" and the number so they sort in order on the boards. Once there's a Chapter 10, it would sort between 1 and 2, so at that point switch to two digits (Chapter 00, Chapter 01…). Claude can rename them all

**Statuses:** To Do, In Progress, Done. A typo makes a new column.
