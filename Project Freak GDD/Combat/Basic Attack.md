Basic attacks make up the core of combat. Almost all combat units will have some sort of special attack including enemies and the main character. 

Player Basic attack - This is literally defined by the weapon the player is using. If no weapon is equipped [[Hazen]] will use a besic [[Unarmed Attack]]. See [[Weapons]] for more info

Enemy Basic Attack - Enemies will still follow the rules for [[Weapons]] such as the swing types and combos but the item they've equipped does not define it but their actual ai combat does.
