These nodes are placed on the [[Rune Field]] ahead of time and are the primary goal for a player to reach by chaining [[Element Rune]]s to reach. When a powered rune is placed directly on top of the [[Ability Node]] it will activate the node provided no other criteria is not yet met.

---
**Shade Enhancements**
the following is a list of possible enhancements an [[Ability Node]] can give to a [[Shade]]

| Type              | Description                                                    |
| :---------------- | :------------------------------------------------------------- |
| [[Shade Ability]] | Gives a shade a specific ability they can use in/out of combat |
| Stat Upgrade      | Massive buff to specific stats                                 |
| [[Evolution]]     | Upgrades the shade itself into a more powerful creature        |

---
**Locked Nodes**
[[Ability Node]]s can have special requirements to be used such as stat minimum requirements or the attached [[Element Rune]] must be of a specific type or rarity. Some [[Ability Node]]s can even prevent other nodes from being activated like with [[Evolution]] nodes. The list of lockout types are as follows:

| Type    | Description                                                                      |
| :------ | :------------------------------------------------------------------------------- |
| Lockout | Another [[Ability Node]] is preventing this one from being used                  |
| Unlock  | Another [[Ability Node]] being activated allows this one to function             |
| Power   | Attached [[Element Rune]] must be powered (all nodes act this way)               |
| Stat    | Specific [[Character Stats]] must be at a certain level                          |
| Element | Attached [[Element Rune]] must have a specific [[Elemental Affinity]] buff on it |
