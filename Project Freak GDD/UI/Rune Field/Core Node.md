The [[Core Node]] is the central power battery for a [[Shade]]. The amount of power it has is equal to the [[Shade]]'s [[LVL]], plus the power of a core fragment (shard) if one is slotted into it. A core can only ever hold one shard (see Death and Burning Down in [[Shade]]). All nodes connected to the core either directly or indirectly will draw from its power and activated if possible.
