- [[Rune field access points]]: where access points go and what each type can do. Written up in [[Rune Field Access Point]]

## Highlights
- Access points are set: **Advanced** in the hub labs (Black Lantern Bar, then Laughing Man Inn), **Basic** at every dungeon entrance, right before each boss, and usually on Safe and Vault Floors
- Every access point is the same prefab. Its event timeline calls one of two launch functions, and what each type allows lives in code, so it can change without touching prefabs or timelines
- Both types edit runes and slot shards; only Advanced edits every shade slot. Rune crafting happens at other crafting spots, not the field
- The info popup gets built with the real UI from the art pass, not a placeholder ([[Node stat displays]])
