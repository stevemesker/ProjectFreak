**Save Slot**
[[Save slot]]s hold the entirety of a game instance within it. They're a scriptable object that will eventually write the data into an actual save file

**Active Save Slot Index**
What save slot has been selected at startup. This gets saved out to another file so the game knows which slot to use when "continue" has been selected at the start.

---
*Get/Set Current Active Save Slot*
two functions that allow the game to know what the current active save slot is.
