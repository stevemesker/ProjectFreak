This is the complete list of shade abilities:

---
**Melee Physical**

| Name      | Description                                                                                                |
| :-------- | :--------------------------------------------------------------------------------------------------------- |
| Hit       | A regular single melee attack. All shades start with this ability                                          |
| Cleave    | A wide partial cone melee attack in front of the shade                                                     |
| Spin      | A full circle attack that hits everything within range of the shade                                        |
| Cyclone   | The shade makes several spins during the attack                                                            |
| Knock     | single attack that applies a small amount of force to the enemy, knocking them back                        |
| Dive      | Dives forward until it strikes an enemy, knocking them back                                                |
| Mega Dive | Dives forward to a certain range (or until stopped by an obstacle) and damages everything the shade passes |

---
**Ranged Physical**

| Name  | Description                                                                        |
| :---- | :--------------------------------------------------------------------------------- |
| Hit   | A regular ranged attack. If a shade doesn't start with hit it will start with this |
| Blast | A larger projectile that can knock enemies back                                    |
| Lance | Fires a large projectile that can pierce multiple enemies                          |
