[[Shade]]s can become bigger and stronger monsters over time by unlocking [[Ability Node]]s that contain the [[Evolution]] attribute. Evolving into the next tier comes with a huge upgrade to the base [[Character Stats]] of the [[Shade]] and opens up further evolution options later on.

---
**Evolution Ranks**
evolutions are separated in power by rank. a [[Shade]] can never go back down a rank but some evolutions give more than one options in the rank above. So evolution is more of a tree than a linear progression.

The list of rank names are as follows:

| Type      | Description                                                                                                                        |
| :-------- | :--------------------------------------------------------------------------------------------------------------------------------- |
| Bound     | The beginning form of a shade. When a shade dies or a new [[Shade Slot]] is unlocked, this is the form that [[Shade]] will take on |
| Unbound   | The first level of [[Shade]] the player has a choice on. Usually has some basic attacks and can take on [[Elemental Affinity]]s    |
| Ascendant | Largest choice section of the evolution tree, usually around 3 options when entering this tier of evolution                        |
| Legend    | The most powerful form and hardest to unlock                                                                                       |

---
**Evolution Stats**
Each rank roughly doubles the shade's base stats **and multiplies every [[Element Rune]] bonus**. The multiplier is what keeps evolving meaningful all game: late runes give most of a shade's stats, so if evolution only raised base stats, a Legend would barely feel stronger than an Ascendant. A baby tree usually has 3 evolutions after Bound.

| Rank      | Base stats (avg / specialty) | Rune bonus multiplier |
| :-------- | :--------------------------- | :-------------------- |
| Bound     | 3 / 5                        | ×1                    |
| Unbound   | 6 / 10                       | ×2                    |
| Ascendant | 12 / 20                      | ×4                    |
| Legend    | 24 / 40                      | ×8                    |

*Starting guesses. The multiplier and late rune values stack hard, so these will likely get flattened in playtesting. See [[Damage Balance]].*

---
**Evolution Type**
Because all [[Shade]]s can be any [[Elemental Affinity]] type they are organized into [[Evolution Type]]s, typically described by their physical structure. The different [[Evolution Type]]s are as follows:


| Type      | Description                                                                                                                                                                                           |
| :-------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Biped     | walks on two feet, has hands that allows it to carry weapons and operate various human instruments                                                                                                    |
| Quadroped | walks on 4 feet, usually cannot operate instruments but is typically the fastest type of [[Shade]]                                                                                                    |
| Swimming  | only peaks a portion of its body outside of the player's shadow, allowing it to become temporarily invulnerable as it hides between realms. Can also slip under locked doors and through small spaces |
| Flying    | is not impeded by floor based environmental effects and obstacles                                                                                                                                     |
| Ghost     | generally the weakest [[Shade]] when it comes to [[HP]] and [[DEF]] but can walk through some walls and become invisible to detection                                                                 |
